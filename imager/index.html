rpi-pinball Imager repository

This site hosts the os_list.json that lets Raspberry Pi Imager download and flash the rpi-pinball images published as GitHub Releases. Launch Imager with:

rpi-imager --repo https://sjkowal.github.io/rpi-pinball/os_list.json

Or in the app: App Options → Content Repository → EDIT, paste the URL above, APPLY & RESTART, then choose Raspberry Pi 5 and pick the Pinball Machine entry (not "Use custom") so the OS Customisation step is offered.
