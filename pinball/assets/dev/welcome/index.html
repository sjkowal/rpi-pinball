Welcome to PinbOS Dev

A Raspberry Pi set up for learning to build pinball games with the Mission Pinball Framework (MPF @MPF_VERSION@) and the Godot Media Controller (Godot @GODOT_VERSION@). Everything runs on this Pi; you don't need another computer.

1. Run the sample game

A small sample game is already in your home folder at ~/mpf-project. It needs no pinball hardware.

  1. Double-click Run Pinball Game on the desktop (or find it in the menu under Games).
  2. A terminal opens with MPF's text display, and a Godot window shows the attract-mode slide.
  3. To stop, close the game window, or press Ctrl+C in the terminal.

From a terminal it's the same thing: cd ~/mpf-project && gmc-run.

2. Change it

Machine & rules MPF's YAML config: config/config.yaml and modes/*/config/*.yaml. Open the folder with Edit Game in VS Code.
Screens & sound Godot scenes in slides/, sounds in sounds/. Open the project with Edit Game in Godot.

Save, then run the game again. gmc-run re-imports any images, sounds or fonts you added or changed before it starts.

3. Make it your own game

~/mpf-project is a git clone of sjkowal/mpf-sample. Make a copy of that repository on GitHub, then point this folder at it:

cd ~/mpf-project
git remote set-url origin https://github.com/<you>/<your-game>.git
git push -u origin main

Or start from someone else's project: rm -rf ~/mpf-project && git clone <repo> ~/mpf-project.

Good to know

  • Use Godot @GODOT_VERSION@ if you also edit on another computer. A project saved by a newer Godot may not open here.
  • Use MSDF fonts. On a Pi 5, Godot's default font setup draws text with pieces missing. The sample already has it on: Project Settings → GUI → Theme → Default Font Multichannel Signed Distance Field, and tick Multichannel Signed Distance Field on each font in the Import dock.
  • Use the Mobile or Compatibility renderer. Video must be OGG Theora, and the Pi decodes it slowly.
  • MPF is installed in /opt/mpf/venv; mpf and pip are on your PATH in a terminal.
  • Real hardware: P-ROC and P3-ROC drivers are installed. Add your board to config/config.yaml as MPF's docs describe.
  • This is a development image. When the game is finished, flash a PinbOS game image (MPF @MPF_VERSION@ · Godot MC) to the machine. That image has a read-only system, so a power cut can't break it, and it can start the game at power-on.
